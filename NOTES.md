**Things worth remembering**
- Hwa's build leaves out `gnubg_ts0.bd`. Desktop gnubg uses it when present, so we ship it
  (see PLAN.md §8).
- gnubg's default compiler flags include `-ffast-math` (`configure.ac:589-592`), so "desktop
  gnubg" numbers are not bit-reproducible across builds. See PLAN.md §7 for how we measure that.
- Data files are not in the tarball. They're generated by `makeweights` and `makebearoff` using the
  commands in `Makefile.am:284-292`.
- `sgf_l.c`/`sgf_y.c` (the SGF lexer and parser) are pre-generated in the tarball, so we don't
  need flex or bison.
